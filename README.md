RENYOU is a full-stack e-commerce platform for beauty and skincare products, featuring a customer storefront, an admin dashboard, and Docker-based deployment.

---

## ✨ Features

- Customer storefront
- Admin dashboard
- Product management
- Categories & brands
- Shopping cart
- Wishlist
- Secure authentication
- Order management
- Coupon system
- AI-assisted product recommendations
- Responsive design
- Docker support

---

## 📁 Project Structure

```text
.
├── Renyou-Shop-Project--main--v2/   # Customer application & backend
├── Renyou_Admin_FINALE/             # Admin dashboard
├── docker-compose.yml
├── Dockerfile.backend
├── Dockerfile.frontend.site
├── Dockerfile.frontend.admin
└── .dockerignore
```

- React
- Node.js

- Tailwind CSS
- Docker

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/renyou-ai/Renyou-Shop-Project-.git
```

Build and run the project with Docker:

```bash
docker compose up --build
```
